# Analisis-Big-Data-MapReduce
Análisis de datos utilizando Apache Hadoop, HDFS y MapReduce con Python.

Este repositorio contiene el desarrollo de una práctica académica de procesamiento y análisis de datos utilizando Apache Hadoop, HDFS, MapReduce y Python, mediante Google Colab.

El proyecto incluye la configuración del entorno, la preparación de los datos, la implementación de los programas Mapper y Reducer, la ejecución del procesamiento y el análisis de los resultados.

**Instrucciones:** Abrir el notebook `Analisis_Big_Data_MapReduce.ipynb` en Google Colab y ejecutar las celdas en el orden establecido, desde el inicio hasta el final, para reproducir correctamente el procedimiento y obtener los resultados.
